\# ChangelogAll notable changes to this Docker-based RStudio bioinformatics environment are documented here.\## \[Unreleased]\### Added\### Changed\### Fixed\### Removed\## \[1.7.0] - 2026-10-06\### Added\#### Flow cytometry\- FlowSOM for self-organizing map clustering of high-dimensional flow cytometry data.\- flowCore for FCS file handling and flow cytometry infrastructure.\#### Spatial transcriptomics\- SpatialExperiment for standardized spatial transcriptomics data structures.\- XeniumIO for importing 10x Genomics Xenium data.\- SpatialExperimentIO for importing imaging-based spatial transcriptomics datasets.\- Banksy for spatially aware clustering and domain identification.\- nnSVG for identification of spatially variable genes.\- arrow for reading Parquet-format datasets, including Xenium outputs.\### Environment\- R remains version 4.5.0.\- Bioconductor remains version 3.21.\- Existing v1.6.1 package versions were retained without upgrades or downgrades.\- Package inventory increased from 496 to 525 installed R packages.\- Exact package versions are recorded in `environment/v1.7.0/R\_packages.csv`.\- Runtime information is recorded in `environment/v1.7.0/sessionInfo.txt`.\## \[1.6.1] - Stable baseline\### Added\- Extended single-cell RNA-seq analysis toolkit.\- monocle3.\- CellChat.\- NicheNet.\- clusterProfiler.\- enrichplot.\- Supporting CRAN, Bioconductor, and system dependencies required by these packages.\### Environment\- R 4.5.0.\- Bioconductor 3.21.\- RStudio Server environment retained.\- This version is the current stable working baseline for downstream analyses.\## \[1.6.0]\### Notes\- Intermediate Docker build.\- Exact source Dockerfile was not preserved separately in the repository.\- Retained for historical reference only.\## \[1.5.0]\### Added\- maftools.\- biomaRt.\- TCGAbiolinks.\- DESeq2.\## \[1.4.0]\### Added\- RStudio Server environment.\## \[1.0.0]\### Added\- Initial R 4.5.0 / Bioconductor-based bioinformatics environment.
